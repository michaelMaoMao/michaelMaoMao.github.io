6 轮调研 Loop + gap 全挖 + interrupt demo 实证。目标：搞透得物 AI 工作流选型与 AICoding 主线，论证项目落地。

🔥 核心发现

  1. 得物按场景选型（非统一引擎）：活动搭建=LangGraph / 数仓=Hermes(Nous 开源) / 告警=Spring AI ReactAgent / 第一版活动=Dify / AICoding=Claude Code+SDD
  2. 得物 2026 主线是 “Claude Code + SDD/Spec + MCP”，LangGraph 仅活动搭建一例
  3. Spec 驱动三件套（本会话深挖确立）：id=216 理论总论 + id=213 工程落地 + id=212 项目实战，统一内核=规格锁定意图 → 代理受控执行+验证 → 归档沉淀组织资产
  4. 基础设施层：大模型网关（id=204 六步法）是所有 AI 应用的模型供给底座（接入 +97% / Token -45%）
  5. 都遵循铁律：确定性机制锁定 + 模型只做语义感知（数仓门禁 id=203 是纯规则”机治”的极致案例）
