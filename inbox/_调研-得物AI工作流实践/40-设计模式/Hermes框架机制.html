Hermes 框架机制（Nous Research）

Hermes Agent 框架机制

本文讲 Hermes 框架本身（Nous Research 开源）。得物如何用它见同目录 得物Hermes数仓Agent实践.md。

一、Hermes 是什么

Nous Research 构建的自我改进 AI 智能体（self-improving agent）。核心卖点：唯一内置学习循环的智能体——从经验中创建技能，使用中持续改进，跨会话保持记忆。与 Claude Code / Codex / OpenClaw 同属”自主编码/任务执行 agent”。

不是 IDE 副驾驶，不是聊天机器人封装，是自主智能体——运行越久能力越强。可部署在任何地方（5 美元 VPS / GPU 集群 / serverless），不依赖本地电脑（可在 Telegram 对话同时让它在云端干活）。

二、核心架构

轻量后端 + 重 Agent 循环。与 LangGraph 的”图编排”不同，Hermes 是”agent 运行时”——不预定义流程图，让 agent 自主规划。

三、Skill 系统（关键，区别于静态框架）

Skill 是程序性记忆——智能体创建并复用。

  • Skills 由 Agent 自主创建、自优化（Learning Loop）——这是 Hermes 最核心的差异化
  • 对比：OpenClaw 等是人工编写静态 Skill 文件
  • 兼容 agentskills.io 开放标准，可移植、可共享，Skills Hub 接受社区贡献
  • Curator：skill 生命周期管理（跟踪使用情况、闲置 skill 标记过时、归档、保留备份）

四、记忆系统

跨会话持久记忆——持续增长。

  • 智能体管理的记忆 + 定期提示 + 自主技能创建
  • 基于 FTS5 的跨会话召回 + LLM 摘要
  • Honcho 辩证式用户建模（对用户持续深化建模）

五、工具集（70+ 内置工具，按工具集分组）

web / search / browser / terminal / file / code_execution / vision / image_gen / video / tts / skills / memory / session_search / delegation / cronjob / clarify / messaging / todo / kanban / feishu_doc 等。

六、定时 + 委托（与 loop 教程呼应）

  • cron 定时任务：内置 cron，可向任意平台投递（对应 Datawhale loop 教程的 scheduled loop 形态）
  • delegation 委托：派生隔离子智能体并行处理多工作流；execute_code 程序化工具调用，把多步骤流水线压缩为单次推理

七、部署与平台

  • 6 种终端后端：本地 / Docker / SSH / Daytona / Singularity / Modal（后两者 serverless 持久化，闲置休眠几乎零成本）
  • 20+ 平台：CLI / Telegram / Discord / Slack / WhatsApp / Feishu / WeCom / DingTalk / …

八、Hermes vs LangGraph（核心区别）

维度 Hermes LangGraph
定位 自学习 agent 运行时 可控编排框架
流程定义 Agent 自主（越用越长） 人写图（确定）
学习能力 内置 Learning Loop，自创建自优化 Skill 无（靠人写图）
记忆 跨会话持久 + 用户建模 Checkpointer（状态持久化）
控制方式 自主性强 可控性强（interrupt/HITL）
适合 经验沉淀/自进化的长周期任务 可控状态机/人机中断的流程

一句话：Hermes 是”会自己变强的智能体”，LangGraph 是”你画好图它严格走”的编排引擎。

九、为何得物数仓选 Hermes（非 LangGraph）

得物数仓工作流（埋点需求 → 规则资产）的核心诉求是规则资产化 + 经验自学习沉淀：

  • 每次埋点需求的处理经验要沉淀成可复用规则
  • Hermes 的 Skill 自主创建 + 持久记忆正好匹配——经验越积越多，Skill 越来越丰富
  • LangGraph 的图是人写的、固定的，不会自学习；数仓的”规则”是动态生长的，不适合固定图

对应得物数仓实践的设计：「单 Agent 编排 + 多能力模块 + 看板确认点」—— Hermes 做编排和自学习，看板做人确认。这正是”按场景选型”的范例：需要自学习沉淀 → Hermes；需要可控中断 → LangGraph。

十、研究就绪（特色）

支持批处理、轨迹导出、基于 Atropos 的 RL 训练。由 Nous Research（Hermes / Nomos / Psyche 模型背后的团队）构建，本身就是研究导向——这也是它能做”自我改进”的底气。

十一、与 Claude Code 自进化（第 3 篇）的呼应

得物自建 Claude Code 记忆系统（Hook 采集 + 置信度演化 + 记忆注入）本质是手工实现 Hermes 的 Learning Loop。Hermes 把这套做成了框架级能力（Skill 自创建 + Curator 生命周期 + FTS5 召回）。可对比：自建 vs 用 Hermes 的取舍。
